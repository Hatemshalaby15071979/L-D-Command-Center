# Security Policy

L-D-Command-Center is part of the Hatemshalaby15071979 production-readiness set.
It is pre-production software and has not passed an independent security review.
Do not run it against real infrastructure credentials or production control planes.

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main` (default branch) | Yes — pre-production; treat as unstable |

## Reporting a vulnerability

**Use GitHub Security > Report a vulnerability** (private advisory). Do not open a
public issue containing exploit details, and do not include real credentials,
infrastructure identifiers, or personal data in any report.

Until a maintainer acknowledges the advisory, please also avoid discussing
specifics in public channels.

## Response times

- Acknowledgement: within 7 days of a private advisory being opened.
- Triage / first update: within 14 days.
- These are best-effort targets for a pre-production, single-maintainer project.

## Scope

In scope: vulnerabilities in this repository's code and released artifacts.
Out of scope: dependencies (report upstream), and any local-only or archived
clones not published to this repository.
